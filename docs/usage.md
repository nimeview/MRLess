# Как пользоваться MRLess

Каждое устройство — **своя нода** в локальной mesh-сети. Облака и аккаунтов нет: имя и ID живут только на устройстве.

## Первый запуск

1. Открой приложение (или `bun run app` на Mac).
2. Введи **display name** → Start.
3. Разреши **Local Network**, если система спросит (iPhone / Mac).

## Чаты

- **LAN Mesh** — широковещание всем на Wi‑Fi.
- **DM** — личка с соседом (появляется, когда он онлайн или уже писали).
- **Groups** — закрытая группа: кнопка `+` в списке чатов.

Статусы доставки у своих сообщений: queued → sent → delivered (или failed).

## Соседи и инвайт

Если устройства **на одном Wi‑Fi**, обычно находятся сами (UDP + mDNS `_mrless._tcp`).

Если нет:

1. Settings → **Invite code** → Copy code (или адрес `host:port`).
2. На другом устройстве Settings → **Neighbors** → вставь код или `IP:7421` → Join.

Для связи между разными сетями нужен достижимый TCP (Tailscale, проброс порта и т.п.) — см. invite в Settings.

## Файлы

Картинки в чате подгружаются сами и показываются превью. **Save** в пузыре или по тапу на фото → сохранить в Файлы / Photos / выбранную папку.

Обычные файлы: **Get** (если ещё нет в кэше) → **Save**. Офферы файлов сохраняются локально (не пропадают после перезапуска); байты — в кэше приложения.

## Действия с сообщением

Кнопка `···` на пузыре (или ПКМ):

- **Copy** / **Reply** / **Forward**
- **Edit** / **Delete** — для своих; Delete locally — убрать у себя


## Память (Storage)

Settings → **Open storage**:

- сколько места занимают сообщения / файлы / прочее;
- удалить историю конкретного чата;
- удалить один файл из кэша или purge всех файлов (текст чата остаётся).

## Настройки

- **Transfers** — лимиты размера файла и текста.
- **Chat reach** — hop limit, relay, discovery.
- **Advanced** — порты и bind (обычно не трогать; после смены нужен рестарт).
- **Reset local data** — стереть локальные сообщения/группы/конфиг на **этом** устройстве; ID остаётся.

## Dev на ноутбуке

```bash
cd MRLess
bun install
bun run app          # нода mac + UI http://127.0.0.1:3000
bun run dev:bob      # вторая нода на :3001
```
